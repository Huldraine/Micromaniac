# Micromaniac
## Présentation

Micromaniac est un projet réalisé dans le cadre de la 1re année de Bachelor (B1).

L'objectif du projet est de développer une application permettant de simuler le fonctionnement d'une boutique spécialisée dans la vente et le rachat de jeux vidéo.

L'application permet de gérer les jeux vidéo proposés par la boutique ainsi que les différentes opérations liées à leur vente et leur rachat.

Le projet utilise Java et JavaFX pour créer l'interface graphique.

## Technologies utilisées
* Java
* JavaFX
* Maven
* IntelliJ IDEA
## Lancer le projet

Pour lancer l'application depuis IntelliJ IDEA, il faut utiliser le plugin Maven configuré pour JavaFX.

### Étapes
Ouvrir le projet Micromaniac dans IntelliJ IDEA.
Ouvrir l'onglet Maven situé sur la droite de l'interface.

Dans l'arborescence Maven, aller dans :

Micromaniac → Plugins → javafx

Double-cliquer sur :

javafx:run

L'application devrait alors se lancer automatiquement.
En cas de problème

### Vérifiez que :

Maven est correctement configuré dans IntelliJ IDEA ;
les dépendances du projet ont bien été téléchargées ;
Java est correctement installé et configuré ;
le projet a bien été importé en tant que projet Maven.
Contexte du projet

Ce projet a été réalisé dans un objectif pédagogique afin de mettre en pratique les notions de programmation Java, de programmation orientée objet, de gestion de projet Maven et de création d'interfaces graphiques avec JavaFX.

# Micromaniac

## Overview

**Micromaniac** is a project developed as part of the **first year of a Bachelor's degree (B1)**.

The goal of the project is to develop an application that **simulates the operation of a video game store specializing in the sale and purchase of video games**.

The application allows users to manage the video games available in the store, as well as the different operations related to selling and buying them.

The project uses **Java** and **JavaFX** to create the graphical user interface.

## Technologies Used

* Java
* JavaFX
* Maven
* IntelliJ IDEA

## How to Run the Project

To launch the application from **IntelliJ IDEA**, you need to use the Maven plugin configured for JavaFX.

### Steps

1. Open the **Micromaniac** project in IntelliJ IDEA.

2. Open the **Maven** tab on the right side of the interface.

3. In the Maven project tree, navigate to:

   `Micromaniac → Plugins → javafx`

4. Double-click on:

   `javafx:run`

5. The application should start automatically.

### Troubleshooting

Make sure that:

* Maven is correctly configured in IntelliJ IDEA;
* The project dependencies have been downloaded;
* Java is correctly installed and configured;
* The project has been imported as a Maven project.

## Project Context

**Student Project — Bachelor 1 (B1)**

This project was developed for educational purposes in order to apply concepts related to **Java programming**, **object-oriented programming**, **Maven project management**, and the development of **graphical user interfaces with JavaFX**.
